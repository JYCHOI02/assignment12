# 경력기술서

과제 하나당 한 줄 제목 + 어느 능력에 해당하는지 + 상황·행동·결과(STAR). 모두 9번 서사 문서 강점지도표(T01~T08 과제 목록)와 리추얼 기록에서 가져왔고, 날짜·수치가 불확실한 부분은 넣지 않았습니다.

## 1. 게임 프로젝트 — 버그 수정과 플레이테스트 밸런싱 [자기동기력]

- **상황:** 개발 과제에서 타워 선택·인터페이스가 겹쳐 보이는 돌출 버그가 있었습니다.
- **행동:** AI가 제안한 수정안에 그대로 의존하지 않고, 직접 원인을 찾아 수정했습니다. 밸런스도 AI 제안값이 아니라 실제로 플레이해 보면서 조정했습니다.
- **결과:** 버그 없이 작동하는 게임을 완성했습니다.
- **출처:** 9번 서사 문서 강점지도표 "강점 1·2"의 T02.

## 2. 데이터 대시보드 — 과부하를 고려한 범위 설계 [자기조절력]

- **상황:** 데이터량이 많아지면 SVG 차트가 과부하로 느려질 수 있는 구조였습니다.
- **행동:** 전체 기간을 다 보여주는 대신, 최근 90일로 조회 범위를 제한하는 설계를 직접 정해 적용했습니다.
- **결과:** 데이터량이 늘어도 안정적으로 동작하는 대시보드를 완성했습니다.
- **출처:** 9번 서사 문서 강점지도표 "강점 2"의 T05.

## 3. ALEPH 보안 팀 프로젝트 — 협업 중 자료 공유 [대인관계력]

- **상황:** 팀 작업 중 동료가 작업에 필요한 웹훅(webhook) 메시지 공유를 요청했습니다.
- **행동:** 요청받자마자 바로 공유해, 팀원이 작업을 멈추지 않고 이어 갈 수 있게 했습니다.
- **결과:** 동료에게서 "공유 요청하자마자 공유해주셔서 감사합니다"라는 평가를 받았습니다.
- **출처:** 리추얼 기록 2026-10월 항목(동료 감사 기록, 이름은 가려져 있음).

## (참고) 넣지 않은 항목

- T04(환율 대시보드, WTI API 장애 대응)는 9번 서사 문서 각주에 "납기를 지킨 것은 아니고, 오류를 파악·수정한 예시라 삭제함"이라고 작성자 본인이 직접 취소선을 그어 둔 항목이라 **경력기술서에 넣지 않았습니다.** 넣고 싶으시면 "납기 준수"가 아니라 "장애 상황에서 대안을 찾아 전환"으로만 쓸 수 있습니다.
- T01(첫 웹 배포), T03(UI 재구성), T06~T08(Plan/Do/See, 인증, 패스키)은 사용하지 않았습니다. 자기소개서 본문에 이미 쓴 내용(T01)과 겹치거나, 세 능력에 깔끔하게 걸리는 장면을 고르라는 지침에 따라 뺐습니다. 더 넣고 싶은 과제가 있으면 알려주세요.
